AZTEX FINANCIAL SERVICES WEBSITE

Files
- index.html: website structure and content
- styles.css: colors, typography, layout, and mobile styling
- script.js: mobile menu, animations, range display, and copyright year

Publishing on GitHub Pages
1. Upload all four files to the root of your GitHub repository.
2. Open the repository Settings tab.
3. Select Pages in the left sidebar.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait a few minutes and open the published URL shown by GitHub.

Updating an existing GitHub repository
1. Open the repository and choose Add file > Upload files.
2. Upload the new index.html and styles.css from this package.
3. GitHub will recognize that the files already exist and replace them after you commit.
4. Use a commit message such as: Update Aztex wordmark and branding.

Form delivery
Submissions are configured for kyan.lz@outlook.com through FormSubmit. The first live submission may require a one-time email confirmation.
